# Bookshelf: опис застосунку

## Призначення

Bookshelf - мінімалістичний застосунок для телефона (PWA) для читачів. Він об'єднує особисту бібліотеку, облік
читання, цитати, статистику, вбудовану читанку EPUB і тиху спільноту навколо власних цитат і відгуків.
Принцип приватності за замовчуванням: нічого не публікується, доки читач сам не натисне «Опублікувати».
Інтерфейс українською. Це навчальний проєкт з дисципліни «Конструювання програмного забезпечення».

## Можливості

**Облік читання**
- Реєстрація, вхід, відновлення й зміна пароля.
- Бібліотека: пошук в Open Library за назвою, автором або ISBN; сканер ISBN камерою; додавання вручну (з обкладинкою за
  https-адресою); імпорт з Goodreads (CSV).
- Статуси «Хочу / Читаю / Прочитано / Відкладено», оцінка 1-5, швидке оновлення сторінки, журнал читання,
  перечитування (кілька проходів).
- Цитати й інсайти: улюблені, теги, повнотекстовий пошук, цитата дня, картка для поширення (canvas, 3 шаблони),
  експорт у Markdown.
- Статистика: серія днів, темп, підсумки місяця й року, прогноз завершення книги, графік, річна ціль, «Рік у книгах».

**Спільнота**
- Профіль з нікнеймом `@handle`, пошук читачів, підписки.
- Пости двох видів (знімок цитати; відгук з оцінкою), стрічки «Підписки» і «Усі», лайки, коментарі.
- Скарги, автоприховання після трьох скарг різних читачів, блокування.
- Відгуки й середня оцінка на сторінці книги.
- Модерація командами Artisan.

**Читанка**
- Завантаження власного EPUB (без DRM), безпечне очищення тексту, екран читання з налаштуваннями (шрифт, інтервал,
  теми), збереження позиції, прогрес, що піднімає сторінку книги.
- Збереження цитат з тексту з підсвіткою, «Відкрити в тексті».

**Акаунт і PWA**
- Експорт усіх даних у JSON, видалення акаунта.
- Встановлення на телефон, кеш оболонки застосунку (дані не кешуються).

Детально для користувача: [user-guide.md](user-guide.md).

## Стек

| Шар | Технологія |
|---|---|
| Бекенд | Laravel, PHP 8.4, REST JSON (API Resources, Form Requests) |
| Автентифікація | Sanctum (cookie-сесія для SPA) + Fortify (headless) |
| База даних | MySQL 8.4 (`utf8mb4`), FULLTEXT з парсером `ngram` |
| Фронтенд | Vue 3, TypeScript, Vite, Pinia, vue-router, vue-i18n, Tailwind CSS |
| PWA | власний Service Worker і маніфест |
| Документація API | Scramble (OpenAPI з коду) |
| Тести | Pest (бекенд, на MySQL `bookshelf_testing`), Vitest (фронтенд) |
| Якість | Pint, Larastan, ESLint, vue-tsc, SonarQube |
| Інфраструктура | Docker Compose, GitHub Actions, GHCR, Caddy (HTTPS) |
| Зовнішній сервіс | Open Library (пошук книг, кеш 24 години) |

## Архітектура

```
Телефон / браузер ──► Caddy (HTTPS) ──► nginx ──┬── /           → Vue SPA (статика, PWA)
                                                └── /api, /docs → Laravel (php-fpm) ──► MySQL
                                                                         │
                                                                         └──► Open Library (з кешем)
```

- **Один origin.** SPA й API живуть на одному домені, тому автентифікація це звичайна cookie-сесія без токенів.
- **Шари бекенду:** `Controller → FormRequest → Action/Service → Model`. Доменна логіка в Actions (статуси, прогрес,
  публікація, модерація, імпорт) і Services (`OpenLibrary`, `Stats`, `Epub`, `Goodreads`), доступ перевіряють Policies
  (чужий ресурс дає 404).
- **Маршрути** в `backend/routes`: `api.php` (бібліотека, цитати, статистика, акаунт), `social.php` (спільнота),
  `reader.php` (читанка), `library-import.php` (імпорт). Усе під `/api`, усе потребує входу, крім реєстрації,
  входу й відновлення пароля.
- **Помилки правил** повертаються зі стабільними кодами (`library.page_above_total`, `reader.drm`,
  `social.review_exists`), які фронтенд перекладає українською.
- **Фронтенд:** сторінки в `frontend/src/views`, стан у Pinia (`stores`), запити в `api`, переклади в `i18n`.
- **Дані** описані в [data-model.md](data-model.md).
- **Читанка безпечна за конструкцією:** EPUB розбирається вбудованими засобами PHP (`ZipArchive`, `DOMDocument`) без
  мережі й зовнішніх сутностей, HTML будується з нуля зі списку дозволених елементів без атрибутів; є ліміти на
  розмір, кількість записів і розділів.

## Документація API

OpenAPI генерується з коду бібліотекою Scramble і доступний на **`/docs/api`**
(локально <http://localhost:8000/docs/api>). Там описані ендпоінти бібліотеки, цитат, статистики, спільноти й читанки.
